# إستبرق للأثاث — موقع المعرض

موقع عرض أثاث باللغة العربية، بتصميم خشبي دافئ، يعمل بدون خادم أو قاعدة بيانات.

## 🔗 معاينة الموقع مباشرة

**[افتح الموقع من هنا](https://oalakkad.github.io/estabraq-furniture/)**

> ⚠️ **الموقع الآن نسخة تجريبية للمراجعة:**
> - رقم الواتساب والعنوان وأرقام التواصل **أرقام وهمية** — يجب تغييرها.
> - أسماء المنتجات وأوصافها **مقترحة** — عدّلها كما تشاء. الأسعار كلها «عند الطلب» حتى تُضاف.
> - آراء العملاء **أمثلة توضيحية فقط** — استبدلها بآراء حقيقية أو احذفها.
> - الصور الحالية من واتساب (دقة منخفضة) — الصور الأصلية ستحسّن الجودة.

---

## الأقسام المتوفرة

- الكنب
- الفوتيهات والكراسي
- الطاولات الجانبية
- الأطقم والجلسات

## المميزات

- تصميم عربي كامل من اليمين لليسار (RTL)
- يعمل على الجوال والتابلت والكمبيوتر
- كل أزرار الطلب تفتح واتساب برسالة جاهزة تحتوي اسم القطعة وسعرها
- فلترة المنتجات حسب القسم
- معرض صور مع إمكانية التكبير
- نموذج استفسار يرسل عبر واتساب — بدون خادم وبدون حفظ أي بيانات
- خفيف وسريع: HTML و CSS و JavaScript فقط، بدون أي مكتبات خارجية

---

## كيف أعدّل الموقع؟

راجع الدليل الكامل بالعربي: **[دليل-التعديل.md](دليل-التعديل.md)**

أهم خطوة: افتح ملف [`js/data.js`](js/data.js) وغيّر رقم الواتساب:

```js
whatsapp: "96500000000",   // ← ضع رقمك هنا بدون + وبدون مسافات
```

كل المنتجات والأقسام وبيانات التواصل موجودة في نفس الملف.

---

## هيكل الملفات

```
├── index.html          الصفحة الرئيسية (النصوص)
├── css/style.css       التصميم والألوان
├── js/data.js          ⭐ المنتجات وبيانات التواصل — عدّل هنا
├── js/main.js          محرّك الموقع
├── assets/images/      الصور (منتجات + معرض)
└── دليل-التعديل.md      دليل الاستخدام بالعربي
```

## التشغيل محلياً

حمّل الملفات واضغط مرتين على `index.html` — لا يحتاج أي تنصيب.

Arabic (RTL) furniture showcase website for a store in Kuwait. Warm wood aesthetic.
