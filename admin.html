تسجيل الدخول

أدخل مفتاح الدخول (Access Token) لإدارة المنتجات والأقسام والأسعار.

كيف أحصل على مفتاح الدخول؟
  1. صاحب حساب GitHub يفتح الرابط: github.com/settings/personal-access-tokens/new
  2. في Repository access يختار Only select repositories ثم المستودع
  3. في Permissions → Contents يختار Read and write
  4. يضغط Generate token وينسخ المفتاح ويرسله لك

المفتاح يسمح بتعديل ملفات هذا الموقع فقط. لا تشاركه مع أحد.
